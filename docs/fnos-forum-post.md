## 一、它是什么

SpektraLab 不是滤镜，也不是 LUT。

它把光按 **81 个波长**送过胶片的染料层，再送过相纸——和暗房里实际发生的事一样。所以：

- **换胶片换掉的是整条曲线**，不是套一层颜色；
- **颗粒是感光统计出来的**，随密度变化（高光细、阴影粗），不是贴一层噪声；
- **光晕**是画面高光穿过防光晕层反射回来的结果，位置和强度由胶片本身的厚度与折射决定；
- **放大机的黄、品滤色和预闪**，作用方式和彩色放大机一致；
- 全程在 **ProPhoto RGB** 里计算，只在导出时做一次色域映射。

渲染引擎是 C++ 写的 Vulkan 程序，编译在应用内，不依赖 Python，也没有后台常驻的守护进程。

## 三、主要功能

| 分类 | 内容 |
|---|---|
| 胶片 | **25 种**：负片（Portra 160/400/800、Ektar 100、Gold 200、C200、X-Tra 400、Pro 400H、UltraMax 400…）、反转片（Velvia 100、Provia 100F、Ektachrome 100、Kodachrome 64）、电影卷（Vision3 50D/250D/500T/200T、Verita 200D、CineStill 800T）、黑白（Tri-X 400、T-Max 100、Acros II、HP5 Plus 400） |
| 相纸 | **9 种**：Portra Endura、Supra Endura、Ultra Endura、Endura Premier、Ektacolor Edge、Crystal Archive Type II、2383/2393 电影正片、Ilford Multigrade IV RC（黑白） |
| 胶片效果 | 分层颗粒、光晕、耀光、散射、DIR 成色剂、防光晕层；胶片画幅决定颗粒/光晕的微米尺度 |
| 相机 | 白平衡（色温/色调）、胶片曝光、测光方式（均衡/中央主体/保护高光/保护阴影） |
| 放大机 | 黄/品滤色、亮度、预闪 |
| 影调 | 曲线（RGB + 明度）、亮度、对比、高光、阴影、黑场、白场、饱和度 |

| 其它 | 中英文界面、界面缩放、编辑保存在应用数据目录（不改写原片） |

## 四、系统要求

- **fnOS 1.1.3100 或更高**，x86_64
- 依赖 **nodejs_v22**（应用中心会自动安装）
- **支持 Vulkan 的显卡**：Intel 核显（本机 HD 520 实测可用）、AMD 核显/独显；NVIDIA 需要能正常工作的专有驱动 Vulkan
- 没有可用 Vulkan 设备时自动回退到 CPU（lavapipe）——能出图，但很慢，只建议小图预览
- 内存建议 8 GB 以上；本机 **7.7 GiB** 完成过 6040×4032 的全尺寸渲染与导出

## 五、安装

1. 下载 `spektralab.fpk`（见文末校验和）
2. **应用中心 → 手动安装**（不同版本的入口可能在右上角菜单里）→ 选择该 fpk
3. 安装过程会自动创建独立运行用户 `spektralab`，并加入 `video`、`render` 组（访问显卡需要）
4. 在 **应用设置 → 权限** 里把你的照片共享文件夹授权给它（不授权也能用内置的「上传」目录）
5. 从 fnOS 桌面点 **SpektraLab** 图标进入；也可直接访问 `http://NAS地址:5666/app/spektralab`

导出文件默认写入共享目录 **`spektralab/exports`**。

> 卸载应用不会删除该导出目录里的文件。

## 六、第一次使用

1. **打开照片**：左栏「打开」→ 浏览已授权的共享；也可以把文件拖进窗口，或用「上传」
2. **选胶片与相纸**：默认 Kodak Portra 400 + Portra Endura。黑白请选黑白胶片，相纸会自动配 Ilford Multigrade IV RC
3. **显影前**：调相机白平衡、胶片曝光、测光
4. **显影后**：调放大机滤色与亮度、曲线、曝光
5. **导出**：选格式与色彩空间，文件名可带胶片/相纸信息

支持的输入：RAW（NEF/CR2/CR3/ARW/RAF/DNG/RW2/ORF/PEF 等，LibRaw 解码）、TIFF、JPEG、PNG。

## 七、性能参考（实测）

测试机：**i5-6200U / Intel HD Graphics 520 / 7.7 GiB / 4 线程**，6040×4032（24 MP）NEF。

| 操作 | 版本 1.3.4 实测 |
|---|---:|
| 打开 24 MP RAW（解码） | 3.6 – 3.9 s |
| 实时预览 1600×1068 | 2.4 s |
| 全尺寸 6040×4032 | 12.4 s |

> 1.3.5 起，输出色彩变换改由 **GPU** 完成。在 1.3.4 上，这段 CPU 色彩转换占全尺寸渲染的 **5.4 s**（约 43%）；1.3.5 把它交给原本闲着的核显，全尺寸渲染与导出都会明显变快。

数字会随机器、画幅和效果开关变化，仅供参考。

## 八、已知限制

- **Linux/Vulkan 引擎尚未移植 5 项功能**，界面上会置灰并说明原因：**片边、日期后背、数字中间片、影调蒙版、场景置位**。macOS 版有，这个版本暂时没有。
- 首次打开一张 RAW 需要解码：24 MP 实测 3.6–3.9 秒（一次）；之后调整参数不再重新解码。
- 没有 Vulkan 设备时走 CPU 回退，速度不适合正常使用。
- 界面沿用桌面版比例，**在手机上可用但不理想**，建议用电脑浏览器。
- 单张照片的编辑保存在应用数据目录（sidecar），**不会改写原片**。

## 九、更新日志

- **1.3.6** — 黑白胶片改用 Multigrade 2 号滤色印相：此前的黑白印相偏亮约 0.36 密度、反差约 3½ 号，现在按相纸自身的滤色包印相。
- **1.3.5** — 输出色彩变换改由显卡完成：全尺寸渲染与导出不再有 5 秒多的 CPU 转换，1:1 预览显示更快。
- **1.3.4** — 编辑响应更快：适应窗口时不再渲染全尺寸（只在放大超过预览分辨率或导出时渲染）；拖动滑块时先用低分辨率草稿，松手后补清晰图。
- **1.3.3** — 关闭页面后释放渲染会话；停止应用时清理残留渲染进程。
- **1.3.2** — 修复着色器缓存被禁用的问题（此前每次启动都会重新编译管线）。
- **1.3.1** — 首个 fnOS 版本：统一网关入口 `/app/spektralab`，内置 Vulkan 引擎（无可用设备时回退 CPU）。
